# 待办实例：新建、编辑与删除

## 实例数据

一个 `TodoInstance` 保存：实例 ID、创建时间、提醒时间、可空截止时间、可空完成时间、持久化的展开状态、可空的来源模板/周期标识，以及根 `TodoTask`。来源模板 ID 与来源周期 key 必须同时存在或同时为空。

## 新建待办

1. 用户点击“添加待办”，控制器在内存中构造一个尚未入库的实例：名称“新待办”、提醒时间为当前时间、无截止日期、未完成、未展开且没有来源模板。
2. 控制器以 `isNew=true` 打开 `TodoInstanceEditor`，编辑器深拷贝该实例作为草稿。
3. 用户可修改根名称、日期和任务结构；根节点没有权重编辑器，只有非根节点可改权重。
4. 点击“保存”时，编辑器完成当前表单、校验完整载荷，并把实例追加到 `payload.instances`；“放弃新建”只关闭对话框，不产生事件。

## 编辑现有实例

- 点击卡片标题或任务图节点会打开相应任务节点的编辑器；根节点显示实例日期，子节点显示任务占比。
- 编辑器的结构区只显示“当前正在编辑节点”的直接子任务；打开更深节点前会先把当前输入固化到同一份草稿，再切换对话框上下文。
- 普通“保存”只替换该实例，不会因为它来自周期模板就自动改变模板，已经生成的实例始终可独立编辑。
- 如果实例仍能找到 `sourceRuleId` 对应的模板，根编辑器额外显示“保存并覆盖周期模板”；该操作在保存实例的同一事务中，用实例当前任务树生成一棵全新 ID、全部未完成的模板树，模板的周期与游标不变。

## 删除

- 删除实例根任务等价于从 `payload.instances` 移除整个实例，必须先经过页面级确认框。
- 删除非根任务只删除该节点及整棵子树，并按任务结构规则重接它的直接后继；实例本身保留。
- 在展开的实例任务图上右键某个子任务也会走确认后删除子树的路径。
- 删除动作不反向删除或修改来源周期模板。

## 列表上的即时操作

- 卡片根复选框和任务图复选框只允许切换叶节点；非叶节点显示派生完成状态且不可直接勾选。
- 展开/收起实例会修改 `instance.expanded` 并持久化，因此可撤销/重做。
- 横向拖动任务图中的任意节点实际移动它所属的整个依赖组，规则见 [`task-structure.md`](./task-structure.md)。
- 卡片每次渲染或完成状态变化后按派生状态重新排序，规则见 [`dates-status-order.md`](./dates-status-order.md)。

## 主要实现链

`TodosController.#openNewTodo/#openInstanceDraft` 负责创建和挂接编辑器，`TodoInstanceEditor` 负责草稿与 `buildNext`，`tasks.ts` 负责不可变任务树操作，最终统一交给 `TodosController.#commit`。
