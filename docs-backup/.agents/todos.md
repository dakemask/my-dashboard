# 待办

## 1. 目的与范围

待办模块用于把顶级事项拆成递归子任务，并用同级递进链、占比进度、提醒/截止时间和独立周期规则管理执行顺序。模块自动保存到本机，账户模式下通过 Shared 手动上传、拉取和处理冲突。

模块不提供标签、多人协作、自动上传、云端合并、子任务独立日期或后台 Service Worker。周期补建只在待办模块页面成功启动、重新获得焦点或跨过周期边界时发生。

当前业务格式是 Shared 管理的 schema v1；业务 payload 和 `todos.json` 不包含 schemaVersion 或任何凭据、revision、冲突等系统元数据。

## 2. 业务数据与不变量

`TodosPayload` 包含 `instances` 和 `rules`：

- 顶级实例保存创建、提醒、截止、完成时间，跨设备同步的展开状态，来源规则/期次和完整任务树；有限时间为 UTC ISO，`deadlineAt: null` 表示无限远。
- 任务节点保存 UUID、名称、占比、叶子完成状态、同级前驱 ID 和直接子任务。根节点占比固定为 `-1` 且没有前驱。
- 同一父节点的直接子任务只能组成若干单链；每个节点最多一个同级前驱和后继，不允许跨层引用、悬空引用或环。
- 非叶子完成状态由全部子任务递归完成得出，不能直接勾选；后继只有在前驱整棵子树完成后才能勾选。
- 负占比规范为 `-1` 并表示自动分配；具体占比为 `0～1`。有自动项时均分具体值以外的余额；全部具体指定时总和必须为 1。
- 叶子进度为 0 或 1，父级按直接子任务的有效占比递归加权。占比为 0 的未完成子任务仍阻止父任务完成。
- 周期规则保存每周/每月类型、无完成状态的任务树模板，以及两种周期各自的已生成期次游标。删除实例不会回退游标，因此不会重新生成。

## 3. 日期、排序与周期

- 新普通待办默认立即提醒、截止无限远。具体日期按设备本地时区解析 `YYYYMMDDHHmm`，至少完成 `YYYYMM`；残缺的后续两位字段忽略，缺失字段取最早合法值，越界字段向合法范围夹取。
- 任意负数截止输入表示无限远，任意负数提醒输入在提交时取当前时间。相对天数仅接受非负整数，设置时一次性换算为绝对时间。
- 提醒不得晚于截止；后设置的字段优先，必要时把先设置字段校正到相同时间。
- 未完成实例依次分为已截止、已提醒未截止、未提醒，完成实例最后展示；组内分别按逾期最久、最早截止、最早提醒、最近完成排序。
- 顶级状态使用红、黄、蓝、灰边框，所有子任务继承顶级颜色。
- 每周实例在本地周一 00:00 提醒、下周一 00:00 截止；每月实例在本地月初 00:00 提醒、下月初 00:00 截止。离线遗漏期次在下次打开模块后逐期补建。
- 周期实例是普通实例且不会增殖。实例可以选择只保存自身，或把名称、完整结构、递进关系和占比覆盖回来源模板；规则修改和删除不影响已有实例。

## 4. 用户操作

- 主区提供加长的“添加待办”按钮，右侧“周期待办”按钮打开独立模板管理弹窗。弹窗以“周期待办模板”为小标题，模板使用与主页面待办和子任务图一致的卡片、子树框、连线和拖拽逻辑，但不显示复选框和进度条；新增模板入口位于弹窗内。
- 主列表点击任务框进入编辑器；叶子复选框切换完成。取消前驱会级联取消全部后继及其子树。
- 主列表展开后，待办本体保留完整四角圆角，任务图作为下方独立区域显示。任务图按子树分组：带直接子任务的节点与其全部后代由实线框包围，节点位于框内左上方；同级并列组横向排列。父节点先纵向连接到中段水平主线，再由主线分别垂直连接各直接子节点；递进箭头连接前后完整子树的边界。
- 展开区域支持滚轮横向滚动和拖动空白处平移，并在勾选、排序及折叠重开后保持每个待办各自的横向位置。拖动任务节点会以真实依赖组及组内各节点的完整子树为单位调整同级顺序；拖动尚未松手时实时预排预期结果，靠近横向边缘时自动横移，拖动与落点反馈覆盖整个依赖组。周期模板沿用同一套依赖组、完整子树、实时预排和边缘横移规则。右键节点使用与编辑器删除相同的页面内确认流程，删除节点、后代并重连递进链。
- 子任务展示区在勾选、平移和排序时尽量原位更新必要节点与连线，不重建整个展开区域；展开与折叠具有对称动效，进度增减在既有进度条上平滑过渡。
- 页面、子任务图、编辑结构区和弹窗内容等可滚动区域不显示滚动条，但保留滚轮、触控、空白拖动和边缘自动滚动能力。
- 展开状态进入 payload，并在保存和云端同步后跨设备恢复。
- 编辑器内部点击子任务只负责选中。新增并列项创建无前驱兄弟；新增递进项插入所选项与原后继之间；删除链中项会重连前驱和后继。
- 编辑器的子任务结构只展示当前编辑任务的直接子任务；所有直接子任务使用紧凑、等高的单层纵向列表。同级递进关系用黑色细线从前项右侧偏下位置短距离回勾至后项右侧偏上位置，两端使用镜像倾角并配小箭头；同一任务框的进入点和离开点互不重合。编辑区不显示额外的依赖链容器，子任务自己的下级结构需打开该子任务后查看和编辑。结构区域保持固定尺寸并独立滚动，不让子任务数量改变弹窗尺寸。
- 编辑器中拖动递进链任一节点都代表移动整个依赖组，只调整同级组顺序，不改变链内依赖；非链首节点同样可以发起整组拖动，编辑器以同组全部直接子任务的实时预排和统一状态反馈移动范围，拖至结构区上下边缘时自动纵向滚动。
- 可点击和拖拽操作使用食指光标，文字使用文本光标，展示区空白平移使用移动光标；其他区域使用普通光标。
- 默认文字按钮和纯图标按钮为 42px、图标为 20px，紧凑控制为 36px；键盘焦点使用模块强调色的 3px `focus-visible` ring，禁用控件统一降低到约 `.48` 不透明度。
- 编辑只由明确的“保存”按钮提交；关闭按钮、Escape 和遮罩点击均取消草稿。校验失败时保持打开。对话框动作依次为“取消→确认”，破坏性确认放在最后且初始焦点落在取消；只有当前流程可安全取消时，Escape 和遮罩才关闭，关闭后焦点回到触发控件。busy 阶段禁止关闭并展示当前阶段。
- 每个完成动作立即自动保存到本机，但不显示重复的底部保存成功提示。业务命令、撤销或重做一旦成功，就保留新 payload；若随后的自动保存失败，只显示持久的未保存横幅和重试入口，不把已经成功的命令误报为失败。
- 普通和成功 toast 保持 4200ms 并使用 `role=status`；短暂错误保持 6200ms 并使用 `role=alert`。字段校验和自动保存失败不自动消失，留在原位等待修正或重试。
- 提醒和截止日期在主编辑器中只显示当前值，点击后打开小型日期设置弹窗。删除确认同样使用页面内弹窗，不调用浏览器原生确认框。
- 页面保留 `Ctrl+Z`、`Ctrl+Y` 业务快捷键，不显示撤销/重做按钮；输入控件聚焦时保留浏览器文字历史。

## 5. 代码与持久化定义

| 位置 | 职责 |
| --- | --- |
| `modules/todos/index.html`、`src/todos/main.ts` | 严格 CSP 页面入口和 Runtime 启动 |
| `src/todos/domain/tasks.ts` | 任务查询、完成门禁、权重、进度和任务树增删改的领域规则 |
| `src/todos/domain/validation.ts`、`validationPrimitives.ts` | payload、实体、任务树与基础字段校验 |
| `src/todos/domain/events.ts` | event 校验、apply、invert 和实体差异计算；`domain/index.ts` 保留兼容导出 |
| `src/todos/domain/dates.ts`、`recurrence.ts`、`codec.ts` | 日期解析与换算、周期补建和稳定远端编码 |
| `src/todos/app/persistedCommands.ts` | 区分业务命令结果与随后持久化结果，维护可重试的未保存状态 |
| `src/todos/app/controller.ts` | Runtime hooks、payload/snapshot、保存与历史、周期调度和视图编排 |
| `src/todos/ui/shell.ts`、`icons.ts` | 页面壳、反馈区与基于 Shared helper 的 IconPark 图标 |
| `src/todos/ui/taskGraphView.ts`、`taskGraphConnections.ts` | 实例与周期模板共用的 keyed 任务图、展开恢复和 SVG 连线 |
| `src/todos/ui/taskStructureEditor.ts`、`pointerReorder.ts`、`graphPanController.ts` | 两类编辑器共用的直接子任务结构、横向/纵向依赖组拖拽，以及任务图空白平移与惯性 |
| `src/todos/ui/editorDialog.ts`、`instanceEditor.ts`、`recurrenceEditor.ts` | 共用 dialog 壳，以及彼此独立的实例和周期模板完整编辑流程 |
| `src/todos/ui/dateEditor.ts`、`confirmDialog.ts` | 独立日期编辑和页面内确认流程 |
| `src/todos/style.css`、`src/todos/styles/` | 固定按 base/shell、cards、task-graph、editors、feedback 顺序导入的响应式样式 |

- `moduleId` 为 `todos`，历史容量 200。
- event 使用实体级前后值事务；一次级联、弹窗保存、依赖组重排或周期补建各占一步，inverse 交换实体变化并逆序执行。
- `TaskGraphView` 通过配置统一实例和周期模板的 keyed DOM、展开、连线与滚动恢复；`TaskStructureEditor` 只投影当前任务的直接子任务；`PointerReorder` 统一真实依赖组、长按、实时预排、FLIP、边缘自动滚动和完整清理。
- `settle` 负责在后台远端变化前结算有效弹窗草稿；`project` 在初始化、撤销和重做后以完整 payload 重建页面并清理实时选择和拖动态。
- 远端只管理 `data/todos/todos.json`；采用稳定两空格 JSON 和末尾换行，decode 只解析原始 JSON。
- Shared 管理本地 envelope、schemaVersion、GitHub、编辑锁、同步基线、轮询和冲突；本模块只从 `src/shared` 根入口调用。
