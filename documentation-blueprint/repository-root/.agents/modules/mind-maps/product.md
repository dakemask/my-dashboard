# Mind Maps 产品行为

## 何时阅读

修改资料库、文件夹、脑图、画布、节点、箭头、选择、快捷键或用户可见保存流程时阅读。

只改 payload、codec、schema 或 runtime 接线时读同目录的 [persistence.md](./persistence.md)，不必自动阅读本文；纯粹移动类或拆分文件也不需要本文。

## 产品目的

Mind Maps 让用户在一个资料库中管理多张脑图，并在自由画布上用文本节点和有向箭头组织想法。资料库中的全部文件夹和脑图共同保存、同步和撤销，不是彼此独立的小文件编辑器。

本模块明确不提供富文本、节点样式、自动布局、搜索、复制粘贴画布对象、箭头文字或多人协作。没有分页和虚拟化承诺，也不人为规定业务数据量上限。

## 用户理解的数据模型

- **资料库**包含全部文件夹和脑图，是一次保存和冲突处理的完整边界。
- **文件夹**由路径表示，可以无限嵌套；根目录不是一个可见文件夹。
- **脑图**拥有长期稳定身份。重命名和移动只改变位置与显示名称，不改变其身份。
- **节点**属于一张脑图，保存多行纯文本和画布位置尺寸。
- **箭头**连接同一脑图中两个不同节点的四边中点，具有方向。

以下是反直觉但必须保留的规则：

- 文件夹和脑图是不同类型，因此同一父目录可以同时存在同名文件夹和同名脑图。
- 脑图是否位于文件夹内，要看脑图的父路径；脑图路径与文件夹路径完全相同表示它们是同级同名项目，不表示包含关系。
- 文件夹移动或删除只影响真正位于其子树中的脑图，不能误伤同级同名脑图。
- 文件夹路径必须显式包含祖先；文件夹不能移动到自身或自己的后代。
- 同一父目录、同一类型的名称不区分大小写判重；重命名或移动会先验证整个目标子树，任何冲突都使动作整体失败。

## 资料库操作

- 单击文件夹会选中并切换展开；单击脑图会选中并打开；点击资料库空白区域清除资料库选择。
- 新建位置由当前选择决定：选中文件夹时建在其中，选中脑图时建在其父目录，没有适用选择时建在根目录。
- 新建、移动或历史定位会展开显示目标所需的祖先。恢复最近脑图时只恢复已有展开偏好，不额外猜测展开项。
- 资料库提供新建文件夹、新建脑图、重命名、移动和删除；拖放只能落到现存文件夹或根目录。
- 删除脑图必须确认；删除文件夹必须明确说明将递归删除全部真实后代。
- 名称编辑应当原地、无布局跳动。有效 Enter、失焦或明确提交完成动作；无效输入留在编辑态并解释原因；取消丢弃草稿。
- 相对最近本地保存版本发生变化时，受影响脑图及其现存祖先提供简洁未保存标记；保存成功后标记消失。

名称提交前去除首尾空白并规范 Unicode。空名称、`.`、`..`、路径分隔符和控制字符无效。脑图显示名不保留末尾 `.json`；根目录脑图不能命名为 `revision`，避免远端清单冲突。具体校验算法由领域代码负责，本文只保存用户规则。

## 画布、viewport 与选择

- 资料库浮在画布上方，不改变画布中的业务坐标。
- 滚轮以指针位置为中心缩放；空白处右键拖动平移；文字编辑区域仍保留浏览器原生右键菜单。
- 第一次打开脑图和用户触发“复位”时适配全部节点，并避开当前打开的资料库区域；空脑图使用默认视图。
- 左键拖动画布空白区域进行框选；对象必须完整位于选框中才被命中。普通框选替换选择，按住 Ctrl 时切换框内对象。
- 普通单击替换选择，Ctrl+单击切换单个对象。拖动未选节点前先按同一套选择规则决定移动组。
- 移动、resize、框选和连线接近可见边缘时自动平移；结束、取消或页面结算后必须停止。
- viewport、缩放、平移、悬停和纯选择变化不是业务动作，不进入撤销历史。

具体缩放上下限、默认 viewport 数值和命中容差由代码持有，除非用户以后明确把某个数值设为产品要求。

## 节点文字与尺寸

- 节点只有多行纯文本和矩形 frame；文字不是富文本。
- 点击文字区域直接进入编辑，并尽量保留真实点击落点、光标和文字选择；Enter 输入换行，不提交。
- 文字失焦、点击其他操作或公共命令到来时，按照有效草稿规则提交；没有实际变化时不产生历史步骤。
- 节点移动和 resize 只在 pointerup 时提交最终动作。pointercancel 或结算取消未完成几何并恢复最近已提交状态。
- 删除节点必须在同一业务动作中删除所有相连箭头；一次撤销完整恢复。
- resize 后节点必须保持可操作的最小尺寸，且最终高度能够容纳全部文字。文字测量结果由页面在提交 event 前给出，业务规则不依赖隐藏 DOM 状态。

现有实现中更细的自然宽度、换行收紧和临时 opacity 属于当前交互实现。只有经过用户明确验收并要求长期锁定的部分，才应继续补充到本节，而不是从源码逐句抄回。

## 箭头

- 箭头从一个节点边中点连接到另一个节点边中点，不能自连。
- 完全相同的有向端点组合只能存在一次。
- 添加箭头是单次模式：成功、释放到非法目标、点击空白或再次点击箭头按钮后都退出。
- 箭头创建后不提供端点调整、文字、曲线和样式编辑。

## 保存、同步与离开页面

- 每个已完成业务动作、撤销或重做后立即尝试保存到本机；实时输入、拖动和 resize 过程不保存。
- 自动保存失败不回滚已经完成的业务动作，而是保留未保存状态和重试入口。
- 没有账户时只显示本地保存状态；账户模式的上传、拉取、版本和冲突方向由 Shared 公共 UI 呈现。
- 本模块允许发起同步，但 Runtime 执行前仍需结算名称、文字和 pointer 实时交互。
- 返回首页前先结算有效草稿并等待对应本地保存。若仍未保存，用户可以重试保存、明确不保存返回或取消离开。
- 已保存但尚未上传本身不阻止离开，也不触发浏览器离开提示。

## 业务快捷键

| 键位 | 产品行为 |
| --- | --- |
| 精确 `Ctrl+Z` | 结算当前有效输入后撤销一步 |
| 精确 `Ctrl+Y` | 结算当前有效输入后重做一步 |
| `Ctrl+Shift+Z` | 不作为重做，不执行模块动作 |
| `Alt+1` | 在可见画布中心添加文本节点 |
| `Alt+2` | 进入单次添加箭头模式 |
| `Delete` | 输入中删除文字；画布上下文删除选择；资料库上下文打开删除确认 |

模块不接管 `Ctrl+S`。输入法 composition 期间不能误提交名称或快捷键动作。
