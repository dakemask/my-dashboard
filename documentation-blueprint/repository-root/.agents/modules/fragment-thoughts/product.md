# 碎片想法产品行为

## 何时阅读

修改想法的新增、编辑、删除、版本历史、搜索、草稿门禁、撤销重做或用户可见保存流程时阅读。

只改 payload、event、codec、schema 或 Runtime hooks 时读同目录的 [persistence.md](./persistence.md)。纯样式修正若用户已明确目标，只需遵守全局 UI 规范。

## 产品目的

碎片想法用于快速记录多行纯文本，并保留每条想法历次有效修改的完整正文。列表、搜索和历史面板作用于同一组想法，整个集合共用一次本地保存和云端同步边界。

本模块不提供富文本、标签、分类、置顶、归档、历史版本恢复、自动合并或自动上传。正文不人为设置长度上限，也不在卡片中截断；实际容量仍受浏览器、本机存储和远端仓库限制。

## 想法与版本规则

- 每条想法至少拥有一个版本；最后一个版本是当前正文和最后修改时间。
- 每次有效编辑追加一个完整正文版本，而不是覆盖旧正文。
- 当前正文没有实际变化时退出编辑，不创建新版本。
- 正文是多行纯文本；换行统一处理，全空白正文无效，其他用户空格保留。
- 版本时间代表完成提交的时间，同一想法中严格递增。
- 不同想法允许拥有相同正文。
- 列表按当前末版时间倒序；编辑后该想法移动到顶部。

UUID、时间格式和非法字段的精确校验由领域代码负责。产品层只要求实体身份稳定、历史顺序可靠，损坏数据不能被悄悄修成另一条想法。

## 新增、编辑和删除

- 新增使用多行输入和明确保存动作。有效保存创建新想法、立即尝试本地保存、清空输入并重新聚焦。
- 新增草稿有内容时可以清空；清空有效内容前必须确认。
- 卡片始终完整显示当前正文。进入编辑后在原位置、原排版中编辑，不能因为替换控件、边框或操作区而跳动。
- 编辑只提供保存修改和取消。取消已改变的有效草稿前必须确认；校验失败保留草稿。
- 删除前必须二次确认；确认后整条想法及全部版本一起删除，一次撤销可完整恢复。

同一时刻只允许一份业务草稿：新增草稿或某一张卡片的编辑草稿。存在草稿时，其他新增、编辑、删除、同步、折叠、撤销和重做不能执行，并提示用户先保存、清空或取消。搜索和只读历史仍可使用。

## 撤销与重做

- 模块提供 `Ctrl+Z` 和 `Ctrl+Y` 业务快捷键，不提供撤销/重做按钮或额外提交快捷键。
- 输入控件聚焦时保留浏览器原生文字撤销与重做。
- 焦点不在可编辑控件、输入法未组合且不存在业务草稿时，快捷键才执行模块历史。
- 新增、编辑、删除、历史版本折叠与展开各占一步；输入过程、搜索和历史面板开合不占历史。
- 撤销/重做完成后立即尝试本地保存；保存失败不回滚已经完成的历史动作。

## 搜索

搜索以不区分大小写的纯文本子串匹配当前正文和全部旧版本：

- 当前正文命中时在卡片正文中安全高亮；
- 只有旧版本命中时仍显示当前卡片，并说明命中旧版本的数量；
- 用户可以从旧版本命中提示直接打开对应想法的历史；
- 历史面板突出匹配版本及匹配文字；
- 没有匹配时显示明确空结果。

正文和高亮始终按文本呈现，HTML 字符不能变成页面标记。列表、高亮、旧版本命中计数和历史突出必须基于同一套匹配语义，不能让不同 UI 各自解释搜索词。

## 历史面板

- 历史按旧到新显示一条想法的全部完整版本，只读，不提供恢复某版。
- 桌面可以显示侧栏，窄屏可以显示覆盖式抽屉，但信息和操作一致。
- 每个版本可以独立折叠；折叠状态属于业务数据，会保存并可同步。
- 搜索命中的折叠版本可以临时展开以展示命中，但不改变其持久化折叠状态，也不能在临时展开期间切换折叠。
- 再次点击当前想法的历史入口或关闭按钮会收起；选择另一条想法直接切换内容。

历史版本的编号、标签和精确面板宽度不是产品承诺；当前决定是不显示版本号或“当前”标记，只显示时间。

## 保存、同步和离开

- 每个完成的业务动作立即尝试保存到本机，没有常驻手动保存按钮。
- 自动保存失败时保留当前业务结果和历史，持续显示未保存状态与重试入口。
- 有有效草稿或页面尚未保存到本机时，关闭或离开页面需要提醒；已保存但未上传不触发提醒。
- 没有账户时只显示本地保存；账户模式的上传、拉取、版本、冲突方向和同步结果由 Shared 公共 UI 提供。
- 有草稿时手动上传和拉取被业务门禁阻止。
- 后台远端变化是草稿门禁的特殊情况：有效非空草稿先结算成一个业务动作，使其进入本地冲突判断；全空白草稿取消。该规则不等于自动解决冲突。

## 本文不维护的内容

本文不列 payload interface、五类 event 字段、controller 文件、textarea 镜像层实现或测试覆盖清单。稳定 textarea 和无感编辑是可见结果；具体怎样复用 DOM 由代码负责。持久化选择见 [persistence.md](./persistence.md)。
