# Shared、项目与持久化模块

项目的业务功能由各个模块承载。包含持久化数据的模块自行定义业务数据、业务事件和页面行为，因此数据表示什么、一次操作如何改变数据，以及页面如何呈现这些数据，都属于模块自身的实现。

`src/shared` 是项目为这些模块提供的公共运行基础。模块把自己的定义和页面接入点交给 Shared，Shared 再让这份模块数据进入项目统一的持久化与同步流程。模块不需要在自身代码中实现一套完整的保存、历史和云端运行链路。

双方主要在模块定义、启动入口、运行时调用和同步状态展示处连接。模块决定保存什么以及业务变化如何发生；Shared 负责让这些数据和变化按照项目共同的方式运行。
