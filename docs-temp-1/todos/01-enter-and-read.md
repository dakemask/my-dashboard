# 进入页面与查看待办

## 用户如何进入和离开

用户可以从首页点击“待办”，也可以直接访问 `/modules/todos/`。页面左上角的首页图标返回项目首页。

启动完成后，页面由三部分组成：

1. 顶部显示模块名称、本地保存与云端同步状态。
2. 操作栏提供“添加待办”和“周期待办”。
3. “待办事项”区域显示实际待办；没有数据时显示“还没有待办。先创建第一项吧。”

运行环境尚未准备好时，新增入口不可用。启动失败时，页面显示“待办未能启动”，说明本机内容没有被修改，并提供返回首页的链接。

## 用户如何读一张待办卡片

一张待办卡片从左到右提供：

- 展开或收起子任务图的按钮；没有子任务时不可展开。
- 最外层任务的完成复选框；有子任务时，整体完成状态由子任务推导，不能直接勾选。
- 待办名称；点击后编辑最外层任务。
- 截止时间；没有截止时间时显示“无截止日期”。
- 整体进度条。

展开后，任务图会显示所有子任务、递进关系和嵌套层级。任务图较宽时，用户可以横向滚动；鼠标可在图的空白区域拖动，触屏可横向滑动。页面会在当前打开期间保留各任务图的横向位置。

待办的展开状态属于待办数据，刷新后仍会恢复。周期模板的展开状态只服务于当前页面查看。

## 状态与排序

未完成待办有三种时间状态，完成待办单独归类：

| 状态 | 用户看到它的条件 |
| --- | --- |
| 已截止 | 当前时间已经到达截止时间 |
| 已提醒 | 尚未截止，当前时间已经到达提醒时间 |
| 未提醒 | 当前时间还未到提醒时间 |
| 已完成 | 所有叶子任务都已完成；该状态优先于时间状态 |

列表优先级固定为：已截止 → 已提醒 → 未提醒 → 已完成。

同一状态内的顺序为：

- 已截止：截止时间越早越靠前。
- 已提醒：截止时间越早越靠前；没有截止时间的排在本组最后。
- 未提醒：提醒时间越早越靠前。
- 已完成：越晚完成越靠前。
- 时间仍相同时，较早创建的待办靠前，最后用稳定标识消除并列。

页面不保证在提醒或截止边界到达的瞬间单独刷新。时间状态会在下一次列表重新呈现时更新，例如刷新页面、完成一次待办操作，或周期检查带来列表更新时。
