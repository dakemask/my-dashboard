# Todos 模块

Todos 用来管理一次性待办和周期模板。一个待办可以拆成多层任务；同层任务既可以并列，也可以组成必须按顺序完成的递进链。周期模板会在每周或每月边界生成独立待办。

产品入口是 `/modules/todos/`。用户也可以从首页的“待办”卡片进入，并通过页面左上角的首页按钮返回。

## 操作路由

按需求中最接近的用户动作选择文档：

| 用户意图或需求关键词 | 首选文档 |
| --- | --- |
| 进入页面、看懂卡片、状态颜色、排序、展开任务图 | [进入页面与查看待办](01-enter-and-read.md) |
| 新建、改名、设置提醒或截止时间、删除待办、编辑某个任务 | [新建、编辑与删除待办](02-manage-todos.md) |
| 添加并列/递进任务、任务占比、勾选完成、拖动、右键删除 | [组织子任务与完成进度](03-task-structure-and-progress.md) |
| 新建模板、每周/每月生成、修改或删除模板、覆盖模板 | [管理周期待办](04-recurring-todos.md) |
| 自动保存失败、重试、撤销/重做、上传、拉取、冲突、离开页面 | [保存、同步与恢复](05-save-sync-and-recovery.md) |

常见跨文档需求：

- 修改新建或编辑弹窗时，先读“新建、编辑与删除待办”；若会影响子任务，再读“组织子任务与完成进度”。
- 修改周期实例的表现时，先读“管理周期待办”，再按实例上的具体动作补读普通待办文档。
- 修改任何会持久化的用户动作时，补读“保存、同步与恢复”。
- 只改页面呈现或排序时，通常从“进入页面与查看待办”开始即可。

## 术语

- **待办实例**：用户在主列表中实际执行和勾选的一张待办卡片。文档中简称“待办”。
- **任务**：待办树中的一个节点。最外层任务同时是待办名称；没有子任务的任务称为叶子任务。
- **周期模板**：用于生成未来待办的结构，不直接记录完成状态。
- **并列组**：同一父任务下互不依赖的一条任务链。
- **递进链**：同一父任务下通过前置关系串联、需要依次完成的一组任务。
