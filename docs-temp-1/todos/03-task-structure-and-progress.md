# 组织子任务与完成进度

## 用户如何组织任务

每个任务都可以拥有直接子任务。编辑器只展示当前任务的下一层；用户可通过子任务行右侧的打开按钮逐层进入更深层级。

结构编辑区支持三种动作：

- **新增并列**：没有选中项时，在当前任务下新增一个独立任务组；选中某项时，在该项所在递进链之后新增独立任务组。
- **新增递进**：需要先选中一个直接子任务，在它之后插入新的后续任务。如果原来已有后续任务，新任务会插入二者之间。
- **删除选中**：从当前草稿中删除选中任务及其全部后代，并在需要时重新连接递进链；用户仍需保存编辑弹窗。

新子任务默认名称为“新子任务”，任务占比为自动分配，完成状态为未完成。

## 选择、打开与拖动不是同一动作

- 点击子任务行会选中它，供“新增递进”和“删除选中”使用。
- 点击行右侧的打开按钮会进入该任务，编辑名称、占比和下一层子任务。
- 拖动会移动整条递进链，而不是拆散链内的单个任务。

拖动只能在同一父任务下调整并列组顺序。编辑弹窗中是纵向拖动，展开后的任务图中是横向拖动；触屏需要长按后再拖动。越过层级或把链拖进另一个父任务不属于支持的操作。

## 用户如何完成任务

只有叶子任务可以直接勾选。包含子任务的任务，其完成状态由所有后代任务推导，因此复选框不可直接操作。

递进链遵守前置条件：

1. 前置任务未完成时，后续任务及其内部叶子任务不能勾选。
2. 当前置任务完成后，后续任务才解锁。
3. 用户重新取消某个已完成的前置任务时，它后面的整条递进链会重置为未完成，避免保留已经失效的下游完成状态。

当全部叶子任务完成时，整张待办进入“已完成”；任一叶子任务恢复为未完成时，整张待办也恢复为未完成。

## 进度与任务占比

子任务占比可输入负数或 `0` 到 `1`：

- 负数表示自动分配。
- `0` 到 `1` 表示固定占比。
- 固定占比总和不能超过 `1`。
- 如果同层全部使用固定占比，总和必须正好为 `1`。
- 有自动项时，它们平均分配固定项之外的剩余占比。

父任务进度是直接子任务进度按有效占比加权后的结果；多层任务会逐层计算。叶子任务只有未完成 `0` 和已完成 `1` 两种进度。

修改一个固定占比时，如果当前组合无法继续保留自动项，其他任务占比会按原有效比例重新分配，使同层总占比仍然有效。删除任务后，如果同层只剩固定占比，也会重新归一化。

## 任务图上的快捷操作

展开待办后，用户可以直接：

- 勾选可操作的叶子任务。
- 点击任务名称进入编辑。
- 右键任务并确认删除。
- 拖动任意任务节点来移动它所在的整条递进链。
- 在空白处拖动或横向滚轮浏览较宽的图。

周期模板的任务图不显示完成复选框和进度条，因为模板不保存完成状态。
