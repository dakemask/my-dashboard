# My Dashboard AI 文档（试行）

这里是面向 AI 开发者的项目文档入口。当前先覆盖 `todos` 模块，用它验证一种文档组织方式：先识别用户正在做什么，再进入对应的行为说明；源码和测试只作为定位入口。

## 模块路由

| 用户涉及的产品区域 | 文档入口 |
| --- | --- |
| 待办、子任务、进度、周期待办、待办同步 | [Todos 模块](todos/README.md) |

## AI 使用方式

1. 从需求中提取用户动作，例如“新建待办”“勾选递进任务”“修改周期模板”。
2. 进入模块文档的“操作路由”，只读取与该动作直接相关的文档。
3. 涉及保存、撤销、云端冲突或离开页面时，再补读该模块的数据安全文档。
4. 需要修改实现时，从各文档末尾的“相关入口”进入源码和测试。

文档描述当前产品行为，不代替源码中的类型校验和自动化测试。
